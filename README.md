
# PocketGoods (IOS - Swift/SwiftUI)

PocketGoods is an IOS application built with **Swift** and **SwiftUI**, designed as the native IOS version of PocketGoods.  
The project follows a modular architecture with **CoreApp**, **CoreUI**, **ProductFeature**, **AuthenticationFeature**, **WishlistFeature** modules and **SettingsFeature** modules, focusing on scalability, maintainability, and modern IOS best practices.

---

## 🚀 Tech Stack
- **Language:** Swift  
- **UI Framework:** SwiftUI
- **Dependency Injection:** Swinject
- **Networking:** URLSession  
- **State Management:** Combine / ObservableObject  
- **Testing:**  
  - **Integration Tests:** XCTest
  - **End-to-End Tests:** XCTest

---

## 🛠️ Features
- 📱 Fully responsive SwiftUI for IOS  
- 🔐 Authentication & authorization (Swinject + ViewModel)  
- 🛍️ Product listing & details (productFeature module)  
- ❤️ Wishlist management (wishlistFeature module)
- ⚙️ Application settings (settingsFeature module)
- ⚡ Modern IOS + SwitftUI architecture  

---

## 📂 Project Structure
```
pocketgoods_swift/
```
